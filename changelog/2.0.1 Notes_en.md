# WestDao Core Library - Version 2.0.1 Release Notes

## Wise Execution Simple Tools

[中文版](https://github.com/westwong/westDao/blob/master/changelog/2.0.1%20Release%20Notes.md)

### New Features

- **Java 17 Support**: Starting from the 2.x line, the minimum runtime requirement is **JDK 17**.
- **Spring Boot 3.x Support**: Core dependencies have been upgraded to **Spring Boot 3.2.x / Spring Framework 6.x**, based on the `jakarta.*` namespace.

### Compatibility Notes

- **1.x releases** (such as 1.2.8) remain the **Spring Boot 2.x + JDK 1.8** long-term maintenance line and are not forced to migrate.
- **2.x releases** focus on **Spring Boot 3.x + JDK 17**. If your project has already upgraded to Boot 3.x, it is recommended to use the 2.x line.

For a detailed list of changes and the latest source code, please visit the [WestDao GitHub repository](https://github.com/westwong/westDao).
