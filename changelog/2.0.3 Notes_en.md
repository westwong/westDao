# WestDao Core - Version 2.0.3 Release Notes

## Wise Exectution Simple Tools

[中文](https://github.com/westwong/westDao/blob/master/changelog/2.0.3%20Notes.md)

### New Features

- **Query Enhancements**: `LambdaQuery` now supports `selectDistinct`, `selectCount`, and `selectCountDistinct` methods for easier deduplication and counting.
- **Limit Support**: Added `limit(Integer limit)` method to `LambdaQuery`, `LambdaUpdate`, and `LambdaDelete` to restrict the number of rows affected by the operation.
- **Ordering Refactor**: The `Ordering` interface has been refactored to provide more flexible `orderByAsc` and `orderByDesc` chaining. A new `last(String last)` method has been added to append custom SQL fragments to the end of the JPQL.
- **Result Mapping Optimization**: Improved result handling in `LambdaQuery`. When using `select` to query specific columns, the system now attempts to automatically map results back to entity objects.
- **Force Count Query**: Added `forceSelectCount` method to explicitly trigger a count query in specific scenarios.

### Bug Fixes & Optimizations

- **Type Correction**: Fixed a return type error in `West.queryJPQL` (which previously incorrectly returned `LambdaUpdate`).
- **Performance Optimization**: Count queries now automatically skip `ORDER BY` clauses to improve execution efficiency.

For a detailed list of changes and the latest source code, please visit the [WestDao GitHub repository](https://github.com/westwong/westDao).
