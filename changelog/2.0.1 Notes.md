# WestDao 核心库 - 版本 2.0.1 更新日志

## Wise Exectution Simple Tools

[English](https://github.com/westwong/westDao/blob/master/changelog/2.0.1%20Release%20Notes_en.md)

### 新特性

- **Java 17 支持**：从 2.x 版本开始，最低运行环境升级为 **JDK 17**。
- **Spring Boot 3.x 支持**：核心依赖升级到 **Spring Boot 3.2.x / Spring Framework 6.x**，基于 `jakarta.*` 命名空间。

### 兼容性说明

- **1.x 版本**（如 1.2.8）：依然定位为 **Spring Boot 2.x + JDK 1.8** 的长期维护线，不强制迁移。
- **2.x 版本**：专注于 **Spring Boot 3.x + JDK 17**，如果你的项目已经升级到 Boot 3.x，建议优先采用 2.x 版本。

有关详细的变更列表和最新的源代码，请访问 [WestDao GitHub 仓库](https://github.com/westwong/westDao)。
