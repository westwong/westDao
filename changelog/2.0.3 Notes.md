# WestDao 核心库 - 版本 2.0.3 更新日志

## Wise Exectution Simple Tools

[English](https://github.com/westwong/westDao/blob/master/changelog/2.0.3%20Notes_en.md)

### 新特性

- **查询增强**：`LambdaQuery` 现在支持 `selectDistinct`、`selectCount` 和 `selectCountDistinct` 方法，方便进行去重查询和计数查询。
- **分页与限制**：在 `LambdaQuery`、`LambdaUpdate` 和 `LambdaDelete` 中增加了 `limit(Integer limit)` 方法，支持直接限制操作影响的行数。
- **排序接口重构**：`Ordering` 接口进行了重构，提供了更灵活的 `orderByAsc` 和 `orderByDesc` 链式调用，并新增了 `last(String last)` 方法，允许在 JPQL 末尾追加自定义 SQL 片段。
- **结果映射优化**：改进了 `LambdaQuery` 的结果处理逻辑，在使用 `select` 指定部分字段查询时，系统会尝试将结果自动映射回实体对象。
- **强制计数查询**：新增 `forceSelectCount` 方法，用于在某些场景下强制执行 count 查询。

### 修复与优化

- **类型修复**：修复了 `West.queryJPQL` 返回类型错误的问题（原先错误地返回了 `LambdaUpdate` 类型）。
- **性能优化**：在执行 count 查询时，系统现在会自动跳过 `ORDER BY` 语句，提升查询效率。

有关详细的变更列表和最新的源代码，请访问 [WestDao GitHub 仓库](https://github.com/westwong/westDao)。
